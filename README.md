# Archiv

Archiv is an early-stage, local-first knowledge-work system for preserving, searching, analysing, and producing evidence-backed documents while keeping source data and execution under the user's control.

## Status

The repository is being bootstrapped. The first engineering milestone is a small, independently validated execution and provenance core—not a new autonomous-agent framework or desktop office suite.

## Public-repository safety

Do not commit private documents, personal data, credentials, model keys, production databases, generated user archives, or proprietary test material. Development fixtures must be synthetic or explicitly redistributable.

## Licensing

No open-source licence has been selected yet. Until a licence is added, copyright is reserved and the public source is available for inspection only.

Product work will proceed through reviewed pull requests with evidence-producing acceptance checks.
