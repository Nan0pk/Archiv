## Why this step exists

The strongest available acceptance test for phase C, and cheap to maintain:
build each OOXML fixture with an OpenDocument twin carrying identical content, then
assert equivalent segment and table recovery from both. Since the OpenDocument reader is
already correct, parity *is* correctness, and any future regression in either reader
shows up as a divergence rather than as silence.

Then update the compatibility matrix, which is the project's published claim about what
each format yields and is re-verified against live ingestion.
