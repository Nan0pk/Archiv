# S04 — The remote evaluation adapter, refused unless the archive is marked

**Phase A** · depends on: S03

## Purpose

Add the third model adapter, so `ask` and `report` can be exercised without local GPU
hardware. This is the step the whole of Phase A exists for, and the riskiest change in
the plan — which is why S01 through S03 land first.

## Design, and the alternative that was rejected

The seam is `ModelAdapter.complete(prompt) -> str` (`model_adapter.py:54-57`). The new
adapter implements that protocol and nothing else changes about how `ask` and `report`
call a model.

It speaks **OpenAI-compatible `/v1/chat/completions` over HTTPS**, with base URL, model
and API-key environment variable from configuration. Reasons, recorded in full at
[`DECISIONS.md`](../DECISIONS.md#3):

- Nearly every provider offers an OpenAI-compatible endpoint, so changing provider is
  configuration, not code.
- The eventual local target — Ollama at `127.0.0.1:11434`, already a preset at
  `ui/product.py:23` — speaks the same wire format. Same format both sides is what makes
  the eventual swap a one-command change.
- No new default dependency; reuse the request/response shape already proven in
  `OpenAICompatibleLoopbackAdapter:69-105`.

**Rejected:** widening the loopback validator to accept a remote host. That destroys the
property S01 pinned. The two adapters share a wire format, not a URL policy.

## Capability declaration

```yaml
name: remote-evaluation-model
purpose: Provide a clearly-labelled non-local model so grounded answers can be exercised
  without local inference hardware.
input_schema: ModelConfig with adapter "remote-evaluation"
output_schema: str (the model's completion)
reads: config/model.json; config/evaluation.json; the API key named by api_key_env
writes: nothing directly — callers write run evidence
forbidden_paths: originals/**, derived/**, indexes/**
network_policy: HTTPS to the single configured base URL only. Never a fallback, never a
  second host, never a redirect to a different origin.
timeout_policy: ModelConfig.timeout_seconds, 1-3600
evidence_produced: provenance "remote-evaluation" on every derived artefact (S05, S06)
validator: tests/test_remote_evaluation_adapter.py
```

## Rules this adapter must obey

1. **Refuse without the marker.** Call `check_evaluation_opt_in` before any network
   activity. A missing marker produces `blocked_by_policy` — the existing terminal state
   at `contracts.py:18-19`, currently produced only at `grounding.py:155` and
   `tasks.py:103`.
2. **The secret is never stored in config.** Follow the existing `api_key_env` design
   (`model_adapter.py:26`, `:78-85`): configuration holds the *name* of an environment
   variable. A missing variable is a clear error, not a silent unauthenticated request.
3. **No hidden fallback, ever.** On failure, raise — matching
   `DisabledModelAdapter`'s contract and the `"Archiv will not select a hidden fallback"`
   promise. Never retry against a different model or host.
4. **Fail closed with no network.** The egress-denied acceptance run
   (`.github/workflows/offline-alpha.yml`, `docker run --network none`) must still pass.
   The adapter cannot reach anything there, and the assertion is that this produces a
   clean recorded failure, not a hang or a traceback.
5. **Redirects are not followed** across origins.

## Configuration to add

Provider, base URL and model. The author has indicated a provider other than Anthropic
but has not named it — **record the chosen default in this step's PR and in
[`DECISIONS.md`](../DECISIONS.md#3)**, and keep the field free-form so switching is a
config edit.

## Acceptance

```
tests/test_remote_evaluation_adapter.py::test_remote_adapter_requires_the_evaluation_marker
tests/test_remote_evaluation_adapter.py::test_remote_adapter_is_blocked_by_policy_without_the_marker
tests/test_remote_evaluation_adapter.py::test_remote_adapter_requires_an_api_key_environment_variable
tests/test_remote_evaluation_adapter.py::test_remote_adapter_fails_closed_with_no_network
tests/test_model_boundary.py::test_https_endpoint_is_rejected
```

The last line is deliberate: the S01 test asserting the **loopback** adapter still
rejects `https` is part of this step's acceptance. Adding a remote adapter must not
loosen the local one.

No test may make a real network call. Stub at the transport boundary, as the project
already does for `tesseract` by installing a fake executable on `PATH`
(`tests/test_visual_ocr.py`).
