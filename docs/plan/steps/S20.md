## Why this step exists

Local transcription via `whisper.cpp` (MIT, with MIT weights), pinned as an
installed artefact with a recorded SHA-256 and invoked as a subprocess. It must record
`skipped` when absent, never fabricate text, and never trigger a runtime download — the
egress-denied acceptance run depends on that and `visual_ocr.py:579-624` is the exact
cascade to copy.

**Licence traps, checked during research — do not skip this paragraph.** Default to
`whisper.cpp` with `large-v3-turbo`: MIT code *and* MIT weights, 99 languages, no
attribution burden. Reproducible figures exist (~17.7x real-time on an M3 Ultra;
`large-v3-turbo` is faster than `medium` despite the larger file). NVIDIA **Canary-1B is
CC BY-NC 4.0 — non-commercial, unusable here**, and sources disagree about
Canary-Qwen-2.5B, which currently tops the Open ASR Leaderboard and is therefore the most
likely trap to walk into: verify per checkpoint. Parakeet TDT is CC-BY-4.0, so usable but
attribution must actually be carried. Separately, speaker diarization is a different
licence surface from ASR — WhisperX uses pyannote, which is gated and token-required.

Segments carry `{"origin": "asr", "audio_offset_ms": …, "audio_end_ms": …}` plus engine,
model and language, following the `visual_ocr` locator convention. Because
`reports/formatting.py:37-38` renders every unrecognised locator key, a timestamp
citation then appears in `find` output, `ask` output, the DOCX source table and the
appendix with no further work.
