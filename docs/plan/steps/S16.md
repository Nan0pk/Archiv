## Why this step exists

Reproduced: a workbook cell `B4` holding `=SUM(B2:B3)` over 750000 and 500000
was indexed as the literal string `'=SUM(B2:B3)'`, not as 1250000. A user searching for
the total they remember finds nothing. The hyperlink target on another cell was dropped.
A hidden sheet's contents were indexed with no marker, so hidden content can surface in
an answer with no indication it was hidden.

The cause is `load_workbook(..., data_only=False)`, which yields formula text rather than
cached values. `normalize_odf.py` gets this right: it captures `office:value` **and**
`table:formula`, puts the formula in the locator, and indexes the value. Copy that shape
exactly.

Note that `read_only=True` prevents openpyxl from loading charts and images at all, so
recovering those needs a second non-read-only pass — which must be gated behind a size
ceiling, not run unconditionally.
