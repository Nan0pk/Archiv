# S16 — XLSX: computed values and formulas, hyperlinks, merged ranges, hidden markers, charts

**Phase C** (Recover the content being silently dropped) · depends on: S15

## Why this step exists

Reproduced: a workbook cell `B4` holding `=SUM(B2:B3)` over 750000 and 500000
was indexed as the literal string `'=SUM(B2:B3)'`, not as 1250000. A user searching for
the total they remember finds nothing. The hyperlink target on another cell was dropped.
A hidden sheet's contents were indexed with no marker, so hidden content can surface in
an answer with no indication it was hidden.

The cause is `load_workbook(..., data_only=False)`, which yields formula text rather than
the results a spreadsheet application stores beside each formula. `normalize_odf.py`
gets this right: it captures `office:value` **and** `table:formula`, puts the formula in
the locator, and indexes the value. This step copies that shape.

## Capability declaration

  searched and cited without hiding where it came from.

output_schema: >
  NormalizedDocument with segments and one table per worksheet. Locator shapes are

forbidden_paths: objects/** (originals are never modified), config/**, runs/**
network_policy: none; hyperlink targets are recorded as text and never fetched
timeout_policy: bounded by the ingestion size limit and by ceilings in
  src/archiv/ingestion/normalize_xlsx.py, all checked before any original is stored.

  padding included, every position of the tables built from them, and every link and

## Decisions made in this step

- **Archiv never calculates a formula.** The workbook is read twice in read-only mode —
  once for formula text, once for stored results — and the two are walked in step. A
  formula cell's segment text is the stored result and its locator carries `formula`,
  exactly as written in the file, with the leading `=`.
- **A formula with no stored result is indexed as its formula text**, and its locator
  carries `computed_value` = `not saved in file` (or `empty text` when the stored result
  is an empty string). Files written by libraries rather than spreadsheet applications
  commonly have no stored results. Showing no number is better than inventing one.
- **The stub planned a second, full (not read-only) openpyxl load for charts, gated by a
  size ceiling. It is replaced** by reading the package's own XML parts with the standard
  library, streaming each sheet part. That recovers merged ranges, hyperlinks, hidden
  rows and columns and charts for every workbook, not only small ones, with memory that
  stays flat. Every member of the package, including the parts only openpyxl reads, is
  checked for DTD and entity declarations before openpyxl parses anything.
- **Hidden content is indexed and marked, not withheld.** `hidden` is `sheet` (for a
  hidden or very hidden sheet), `row`, `column`, or `row and column`. Hiding in a
  spreadsheet is a display choice, not access control, and dropping the content would
  be the silent loss this phase exists to fix.
- **A merged range yields one segment**, at its top-left cell, whose locator carries
  `merged` = the range (`A1:C1`). The worksheet's table repeats that value across every
  cell of the range, so a merged header reaches each column under it. The fill is
  clipped to the rows and columns that hold values, so a merge declared across a whole
  row or column creates no empty cells.
- **Tables change shape slightly.** A worksheet's table keeps only rows holding a value,
  and every kept row runs from column A to the last column holding a value on that
  sheet. Formula cells in the table hold the stored result rather than the formula.
- **Hyperlink targets** are separate segments whose text is the target, located by
  `sheet`, `cell` (the link's cell or range, as written) and `hyperlink` = 1, matching
  the Word reader. Internal links are written as `#Sheet!A1`. A link whose relationship
  is missing is skipped, not guessed.
- **Charts** yield one segment per chart, located by `sheet` and `chart` = its 1-based
  position among that sheet's charts: the title, then axis titles, then series names,
  one per line. Chart sheets are read the same way. A chart anchored more than once, or
  a drawing named more than once, counts once, so repeats cannot multiply the work.
- A declared sheet dimension no longer controls how long reading takes: a small file
  that declares a million rows is refused once the position budget is spent.
- The `xlsx` extractor version moves from 1 to 2. The reader moves out of
  `normalize_office.py` into `normalize_xlsx.py`.

## Not in this step

Recorded in the office-spreadsheet `known_limits`: number and date formatting (the
stored value is indexed, so 25% is indexed as 0.25), data-table formulas (only their
stored result is indexed), the values and category labels a chart plots, images,
shapes, text boxes, cell comments and pivot state. Workbooks added before this change
keep their older derivative until `archiv rebuild-derived` is run for them; nothing
rebuilds them automatically.
