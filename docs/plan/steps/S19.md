## Why this step exists

`.wav` is the only accepted audio format, and it is catalogued rather than
transcribed — so a recording in a corpus is currently just a filename. Almost nothing
real is `.wav`: iPhone Voice Memos write `.m4a`, Android writes `.m4a`, `.3gp`, `.amr` or
`.ogg`, and dictaphones write `.mp3` or `.wma`.

Use `ffprobe` as a subprocess for container and codec facts. **Not `mutagen`** — it is
GPL-2.0-or-later, which is a licensing problem inside an Apache-2.0 product. A subprocess
is also how this project already uses `tesseract`, `libreoffice` and `resvg`, so it fits.

Olympus `.dss` / `.ds2` are proprietary; document them as out of scope rather than
half-supporting them.

Media needs its own declared resource budget. The current global policy allows one
subprocess, 60 CPU seconds, 1 GiB of address space and 60 seconds wall-clock — right for
a document, far too small for an hour of audio, and raising it globally would weaken the
fail-closed guarantee for every document format at once.
