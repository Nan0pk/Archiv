## Why this step exists

S18 brings the OpenDocument readers level with the OOXML readers for text tables,
spreadsheet cell values and stored formula results, and presentation tables and speaker
notes. It deliberately stops there, because the remaining phase-C parity work is a
second reader-sized change:

- **Text:** hyperlink targets and footnote or endnote structure. The link text and note
  text are already inline in the paragraph; the reader does not separate them into
  target or note locators.
- **Spreadsheet:** hyperlink targets, merged-range state, and hidden sheet, row and
  column markers. Cell values are already read.
- **Presentation:** chart content, group structure, hidden-slide and hidden-shape
  markers, and placeholder roles. The text inside grouped shapes and hidden slides or
  shapes is already read as ordinary object text.

The OpenDocument reader does not recover these targets, states or structures today, so
the parity tests required here would fail honestly until each is implemented and
recorded in the matrix.
