# S18A — OpenDocument parity for hyperlinks, notes, spreadsheet state and advanced presentation recovery

**Phase C** (Recover the content being silently dropped) · depends on: S18

## Why this step exists

S18 made the OpenDocument reader recover text tables, presentation and drawing
tables, and speaker notes as structure. It deliberately stopped short of the rest of
the phase-C parity surface, because that is another reader-sized change:

- **Text:** hyperlink targets and footnote or endnote structure. Link text and note
  text already appear in the paragraph, but the reader does not separate them into
  target or note locators.
- **Spreadsheet:** hyperlink targets, merged-range state, and hidden sheet, row and
  column markers. Cell values are already read.
- **Presentation:** chart content, group structure, hidden-slide and hidden-shape
  markers, and placeholder roles. The text inside grouped shapes and hidden slides or
  shapes is already read as ordinary object text.

This step reads those targets, states and structures, and makes the OpenDocument rows
of the compatibility matrix describe the result honestly. It does not re-add what S18
already reads: table cell text, spreadsheet cell values, speaker notes, or the text
inside grouped shapes, hidden slides and hidden shapes.

## Decisions made in this step

- **Hyperlink targets are separate segments.** An inline `text:a` keeps its display
  text in the paragraph or cell text, exactly as the Word reader keeps a hyperlink's
  run text. The target becomes a second segment: `{paragraph, hyperlink}` for a
  paragraph, `{table, row, column, hyperlink}` for a text-table cell, and
  `{sheet, row, column, hyperlink}` for a spreadsheet cell. External targets are
  reported as written and never fetched. A target that is absent or empty is skipped,
  not guessed.
- **Notes become structure, not inline text.** A `text:note` of class `footnote` or
  `endnote` is removed from the paragraph's own text, including its citation marker,
  matching the Word reader, whose paragraph text excludes the reference mark. Each note
  body is then read after the document body, located by `footnote` or `endnote` (the
  note's `text:id`, or its 1-based position when the id is absent) and `paragraph`
  within that note. Tables inside a note body are read with the note prefix. Link
  targets inside a note body keep the same note prefix. A note class that is not
  `footnote` or `endnote` stays inline rather than being silently dropped.
- **Merged spreadsheet ranges mirror the Excel reader.** The anchor cell carries
  `merged` with the range reference (`A1:B2`); a covered cell carries no value and no
  segment. The `NormalizedTable` repeats the anchor value across the merge only inside
  the extent that holds a value, which is what the Excel reader does, so the two table
  views stay equal. A repeated row or column that also declares a span is refused
  rather than expanded into overlapping ranges.
- **Hidden spreadsheet state mirrors the Excel reader.** A cell carries `hidden` with
  `sheet`, `row`, `column` or `row and column`. A hidden sheet is a table whose style's
  `table:display` is false; a hidden row or column is a `table:visibility` of `collapse`
  or `filter`. Repeats apply the state to every expanded row or column. Hyperlink
  segments carry the same hidden marker as their cell, and a hidden sheet wins over a
  row or column marker.
- **Presentation groups keep the page object number.** A top-level page child remains
  one `object`, counting from 1 as before. A group (`draw:g`) emits no segment of its
  own; each child is located by the group's base object plus a dot-separated
  `grouped_shape` path, matching the PowerPoint reader. Group nesting is bounded by
  `MAX_GROUP_DEPTH`.
- **Placeholder roles use readable words.** `presentation:class` is mapped to the same
  vocabulary the PowerPoint reader uses where the roles correspond: `title` and
  `subtitle` stay as they are, `outline` becomes `body`, `text` and `object` become
  `content`, `graphic` becomes `picture`, `orgchart` becomes `diagram`, `page` becomes
  `slide image`, `page-number` becomes `slide number`, and `date-time` becomes `date`.
  Unknown classes are kept as written rather than guessed.
- **Hidden slides and shapes are still indexed.** A hidden page carries
  `presentation:visibility="hidden"` on its automatic drawing-page style; every segment
  from that slide carries `hidden: slide`, including its speaker notes, as in
  PowerPoint. A shape on a layer whose `draw:display` is `none` carries
  `hidden: shape`; a hidden group passes the marker to its children. A slide marker
  wins over a shape marker. The layer mechanism is recorded as the OpenDocument
  equivalent of a hidden shape, not as a rendering promise.
- **Chart text is read from the embedded object part, not from a preview.** A
  `draw:object` reference is resolved inside the package; only a relative member is
  read, and a missing, external or non-chart object is skipped. The text is the chart
  title, axis titles and series names, one per line, matching the shared OOXML chart
  text order. Series names are resolved from the chart's own data table by the
  `chart:label-cell-address`; an unresolvable label is skipped rather than guessed. The
  chart object is parsed under the same XML-declaration, node and character limits as
  content.xml.
- **Drawing pages reuse the page reader.** Charts, groups, placeholders and hidden
  markers therefore apply to drawing pages too, with `page` in place of `slide`. This is
  the same composition S18 used for drawing tables.
- **The ODF processor version moves from 4 to 5.** Locator keys and derived segments
  change for text, spreadsheet and presentation documents. Existing derivatives are not
  rebuilt automatically; `archiv rebuild-derived` changes the derived hash, and earlier
  citations for that document fail closed.

## Not in this step

- Spreadsheet chart content, pivot state and cell comments remain outside the
  OpenDocument spreadsheet reader; the presentation chart work here does not claim
  them.
- OpenDocument comments, annotations, alternative text, SmartArt equivalents and
  embedded non-chart objects are not read.
- Speaker notes are still read only from top-level text frames on a notes page. A
  table or group there is still dropped, and a hidden shape there is still not marked.
- Flat-XML presentations do not expose an embedded chart object part, so their chart
  content is skipped. The known limit says so.
- Issue #206 (formula-only spreadsheet cells and frame text order) is not included.
- No format outside the OpenDocument and OOXML office families is widened.


The parity file also holds structural and failure-state tests: a note in a table cell is
not repeated in the cell text; a note body with two paragraphs yields two note
segments; a footnote and an endnote both carry their own prefix; a repeated merged row
or column is refused; a chart object that is missing or external is skipped; an
unresolvable series label is skipped; group nesting beyond the limit is refused; and a
hidden slide's speaker notes carry the slide marker. The live matrix test runs every
family through ingestion, retrieval and citation validation; additional generated page
fixtures pin every declared presentation and drawing locator-key combination.
