# The queue

> Generated view of [`queue.json`](queue.json), which is the source of truth.
> A test asserts the two agree, so they cannot drift. **Do not edit this file by hand.**

Progress is not recorded here. Run `python scripts/plan_status.py` to find the next
incomplete step — it derives that by running each step's acceptance check.

Step ids are stable labels, not indices. Inserting a step (`S04A`) is preferred over
renumbering, so references in commit messages and pull requests stay valid.
